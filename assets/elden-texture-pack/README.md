# Elden HD-2D — Paquete de texturas

Paquete independiente de suelos, arquitectura, materiales, overlays atmosféricos y objetos. Las imágenes no se agregan a la página interactiva.

## Uso

Los archivos de `suelo/`, `arquitectura/` y `materiales/` están preparados como texturas opacas de 512 × 512 px. Los archivos de `overlays/` tienen fondo transparente y se deben dibujar como capas superiores. Los elementos de `objetos/` tienen transparencia y están listos para composición.

## Dirección

La paleta conserva carbón, piedra, latón, ceniza y azul rúnico. Las texturas muy saturadas quedan reservadas para señales mágicas o puntos de interés.
